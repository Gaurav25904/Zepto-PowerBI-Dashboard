# 📊 Zepto Power BI Dashboard

## 🚀 Project Overview

This project presents an interactive Power BI dashboard built to analyze and visualize Zepto business data. The dashboard provides meaningful insights into product performance, sales trends, customer behavior, and key business metrics through dynamic visualizations.

## 🎯 Objectives

- Analyze overall business performance
- Track important KPIs
- Identify trends and patterns
- Enable data-driven decision making
- Create an interactive and user-friendly dashboard

## 📈 Dashboard Features

✅ Interactive Filters and Slicers

✅ KPI Cards for Key Metrics

✅ Sales Trend Analysis

✅ Category-wise Performance Analysis

✅ Product Insights

✅ Geographic Analysis

✅ Dynamic Visualizations

## 🛠️ Tools & Technologies Used

- Power BI Desktop
- Microsoft Excel / CSV
- Data Cleaning
- Data Modeling
- DAX (Data Analysis Expressions)
- Data Visualization


## 📊 Key Insights

- Business performance can be monitored through KPI indicators.
- Interactive filtering enables detailed analysis.
- Visual reports help identify high-performing segments.
- Trends and patterns support better decision-making.
